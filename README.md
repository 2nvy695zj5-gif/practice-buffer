# Practice Buffer (Geode mod)

Click buffer for Geometry Dash 2.2081 / Geode 5.11. See about.md.

## Build

Locally: install the Geode SDK + CLI, then run `geode build`.
Or push to GitHub: the workflow in .github/workflows builds it, and the .geode file is under Actions → latest run → Artifacts.

Drop the .geode file into the `geode/mods` folder.
