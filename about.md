# Practice Buffer

A click buffer for practicing: if you press jump a few frames too early, the click is held and applied when you land or touch an orb.

- Only active in practice mode by default
- "Buffer ON" label in the corner whenever it's active
- Adjustable window (1–16 frames), orbs and ground jumps can be toggled separately

Not for record runs. Buffered inputs will not be accepted on lists like the Demonlist.
